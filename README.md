# Cat-ch

> **Every Cat Has a Story. Every Player Can Make a Difference.**

**Cat-ch** is a cross-platform (iOS + Android) mobile game that blends the
exploration-and-collection feel of location-based games with the warmth of cozy
life simulators. Players walk their real neighborhoods, discover **real cats**,
photograph them, and — after on-device AI verifies the subject is a genuine cat —
receive a stylized, adorable virtual companion to care for, collect in a
**CatDex**, and grow attached to. Over time, the game channels its community and
revenue toward **real-world animal welfare**.

The experience is designed to be **cozy, wholesome, relaxing, rewarding, and
community-driven** — never competitive, aggressive, or exploitative. Animal
welfare always comes before gameplay.

## Status

🚧 **Phase 0 — Foundations.** The planning documentation is complete and the
Flutter app scaffold is in place (Riverpod + Supabase + Sentry wiring, v1
database schema, and the `generate-companion` Edge Function boundary). Feature
bodies — camera, map, on-device detection, companion generation — arrive in
Phase 1. See **[DEVELOPMENT.md](DEVELOPMENT.md)** to get it running.
